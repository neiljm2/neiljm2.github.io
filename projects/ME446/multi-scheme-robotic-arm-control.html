Project Overview

  • My Role: Wrote the real-time C code and tuned gains on DSP hardware for active motion stability.
  • Objectives: Achieving sub-millimeter trajectory tracking accuracy and smooth end-effector collision dampening.

Control Architecture

We developed a multi-loop feedback scheme that runs in real-time on a digital signal processor (DSP). The inner loop regulates motor currents at high frequencies, while the outer loop processes joint trajectory errors, dynamically adjusting the control gains based on the arm's active pose and velocity states. The schema tested impedance control, gravity compensation, and feedback linearization to achieve sub-millimeter path tracking accuracy.
